# JavaScript Fundamentals Exercises

This repository contains my functional programming implementations for core JavaScript logic. I built these exercises to practice data types, loops, and conditions.

## 📁 Repository Structure
* `01-basic-calculator/` - Handles basic arithmetic using switch blocks.
* `02-grade-calculator/` - Evaluates custom score ranges using clean conditions.
* `03-even-odd-checker/` - Checks integer remainders with the modulo operator.
* `04-age-checker/` - Categorizes life stages with strict bounds checks.
* `05-temperature-converter/` - Converts formulas with rounded decimal outputs.
* `06-table-generator/` - Generates a 1-to-12 mathematical iteration grid.

## 🛠️ Concepts Implemented
* Parsing raw strings securely into clean floats.
* Tracking boundary conditions for unexpected user behavior.
* Injecting dynamic list items directly into DOM structures.
* Resetting container blocks before running loops.
